The first ReVibe release: a desktop app for Mistral Vibe, carried on from VibeDeck under a new name, with a Linux AppImage and Windows builds.

**Downloads**

- `ReVibe-1.0.0-x86_64.AppImage`: Linux. `chmod +x` it and run it.
- `ReVibe-1.0.0-setup.exe`: Windows installer.
- `ReVibe-1.0.0-portable.exe`: Windows, a single file with nothing installed.

You need the Vibe CLI: `uv tool install mistral-vibe`, then `vibe --setup`. The Windows builds are new and less tested than Linux, and they are not code-signed.

**New in 1.0**

- Review the agent's changes per file and per hunk, and rewind or fork from any of your messages.
- Queue messages while the agent works, run `!` shell commands, and stop a run with Ctrl+.
- Worktree sessions, compaction, and a project and branch strip under the message box.
- An activity panel for subagents and background processes.
- MCP servers, connectors and registry skills managed from the app; repeating prompts; dictation.
- Sessions named by Vibe; done, failed and stopped marks in the sidebar; pinned sessions; project menus.
- Sounds from your system theme and desktop notifications, switchable per event.
- Animated backgrounds, settings in sections, a keyboard shortcut list on `?`, and a short first-run tour.
- Faster start: one app-server and saved model lists.
- Supports Vibe 3.0.4, including model-defined thinking levels.

**Moving from VibeDeck**

ReVibe keeps your sessions, settings, keys and Mistral sign-in. On Linux, the script install puts a `revibe` command next to the old `vibedeck` command, which keeps working.
